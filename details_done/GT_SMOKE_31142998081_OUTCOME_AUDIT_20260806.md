## Verdict

**Rejected as an outcome-preserving treatment.** The workflow completed with all ten task and merge jobs green, but its verifier outcome is **8/10**, below the frozen GT-off baseline's **9/10**. This is not the historical outer-timeout artifact: all ten trials returned verifier rewards and all ten central receipts report `censored=false`.

Therefore neither aggregate resource reduction nor a green workflow may be cited as a GT win, and the 89-task run remains blocked.

The immediately preceding run `31142795616` is not benchmark evidence. Its plan-job provider ping hit the explicit 150-second external-provider timeout; no task matrix was spawned. One controlled retry at the exact same commit and inputs passed the provider ping and produced this audit run.

## Causal boundary for the new solve loss

The loss cannot honestly be assigned to the five payloads simply because the treatment failed:

1. The normalized initial provider message list for `schemelike` was byte identical in GT-off and GT-on (two messages, 4,224 bytes, SHA-256 `c8b2a358828cf6b4ddbb7632bfad959a17e8705197814bb03c88b4a41dc0e94d`).
2. The first sampled model response already differed before any GT-visible evidence: GT-off emitted two exploratory commands; GT-on emitted a semantically similar combined exploratory command. Temperature-1 sampling therefore diverged at turn one.
3. Shadow preflight did not alter any command, and the schemelike completion controller made no auto-submit. The sole GT-visible payload was a 135-character, source-grounded `GT_EDIT_CHECK` after action 71. It named `eval.scm` and the exact calculator validation command, reached call 72 on time, and the next action followed its anchor.
4. The same trajectory underwent 98 deterministic provider-view transformations and later replaced `eval.scm` at action 96 before ending at the step cap. Thus preflight and command rewriting are ruled out; the evidence does not distinguish temperature divergence from an effect of the later active payload or deterministic compaction transform.

The next work is therefore a provider-free request-diff/replay audit followed by a separately authorized matched ablation that isolates `active` evidence from the bounded compaction and completion/progress transforms. Do not retune feature triggers, add generic advice, or launch the 89-task run from this result.
