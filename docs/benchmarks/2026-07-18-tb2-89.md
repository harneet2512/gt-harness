## Non-passing tasks (36)

25 clean test failures + 11 infra exceptions (10 `AgentTimeoutError`, 1
`NonZeroAgentExitCodeError`). The exceptions cluster on the resource-heavy tasks
(in-container QEMU VMs, MIPS-Doom, CIFAR training) that hit the agent wall-clock
timeout at the 100-iteration cap or OOM the container — infra/resource limits, not
harness defects (zero harness crashes or tracebacks across all 89 trials).

## Reproduce

```powershell
# from repo root, in a fresh PowerShell (PYTHONUTF8 must be set before Harbor runs)
.\scripts\tb2_slice.ps1 -NTasks 89
```

The launcher loads the gateway token from `.env`, forces UTF-8, stamps a unique
job name, and writes `results/terminal-bench/<job>/result.json`. Do **not**
`-RetryErrors` a completed run — it re-runs flaky tasks non-deterministically and
overwrites the clean artifact.
